# Invest Trainer — Simulateur de trading (paper trading)

Interface pro de simulateur de trading en dark mode, avec graphique candlestick temps réel, order book, watchlist et portefeuille.

## Lancer

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:5173

## Build production

```bash
npm run build
npm run preview
```

## Stack
React + Vite + TypeScript + Tailwind CSS v4 + Lightweight Charts + Zustand + Framer Motion + Lucide.
